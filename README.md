# HOLDLE 数据助手（holdle-data-skill）

HOLDLE AI 投研助手的**客户端数据组件**：让 AI 助手自动拉取 A股/港股/美股行情数据（月K/周K/日K/财报/实时行情），配合 HOLDLE 方法论做投研分析。

> ⚠️ 本工具仅提供**公开行情数据**，不包含任何投资判断，**不构成投资建议**。

## 这是什么

HOLDLE AI 投研助手由两部分组成：

| 组件 | 位置 | 作用 |
|:--|:--|:--|
| **holdle-ai MCP** | 云端服务（ai.holdle.com） | 知识库检索（HOLDLE 方法论） |
| **本仓库（数据助手）** | 你的电脑 | 拉取真实行情数据 |

两者配合：AI 先拉数据，再检索方法论，然后结合分析回答你。

## 怎么用

1. 让 AI 助手配置 MCP（见安装说明，或直接告诉 AI「安装 HOLDLE AI 投研助手」）
2. 把这个仓库的 `holdle-data-skill` 文件夹放到你的工作目录
3. 安装依赖：
   ```bash
   python3 -m pip install baostock tickflow akshare pandas
   ```
4. 然后就可以问 AI：「帮我分析 600519」「复盘一下 NVDA 这十年」

## 复权口径（重要）

- **历史复盘/回测**（复盘XX/回测十年/**分析某年-某年**/**历史**/当时/上市以来/**第一次入场**/**上次入场**/过去N年）→ 后复权（`--adjust backward`，历史口径固定）
- **当前/近期/现状判断**（是否状态A/突破参考价/入场参考价/近期会不会有机会/近期走势 /**分析 XX 股票 / XX 怎么样** 这类没带时点词但想看现状的问法）→ 前复权（`--adjust forward`，与行情软件一致）
- **拿不准/无明确历史意图 → 一律前复权**；只有明确出现「历史/复盘/回测/年份区间」才用后复权
- 🔴 **现状判断必须显式传 `--adjust forward`**，不要依赖脚本默认值（默认值是后复权，仅为兼容历史用法）
- **三条硬规则**：① 同一回答里，历史事件（开窗月/绿柱日/入场参考价区间）用**后复权**回看，当前价与需要和软件对账的数字用**前复权**，并分别注明；② 会话内意图从现状漂到历史（或反向）**必须重新拉取**，不得复用已拉取的 CSV；③ 判意图要**结合会话上下文**，不只看单句关键词（上一轮在复盘历史，本轮的「帮我看看 XX」即承接历史）
- AI 回答涉及价格时，会自动注明使用的复权格式

## 手动运行（可选）

```bash
python3 holdle_data.py 600519 ./data --adjust forward   # 前复权（当前判断，推荐显式传参）
python3 holdle_data.py NVDA ./data --adjust backward    # 后复权（历史复盘）
```

输出：月K/周K/日K CSV（含 MACD 指标）+ 财务（A股/港股/美股，含**归母净利率**列）+ 实时行情。

## 🆕 v1.0.8：内置方法论判定（2026-10-26）

前复权模式下，脚本在拉完数据后会**自动算一遍 HOLDLE 方法论判定**，并把结果写成 `{code}_判定.json`：

```bash
python3 holdle_data.py 600519 ./holdle_data --adjust forward
# 输出：holdle_data/600519_判定.json
```

**判定内容**：状态A（是否成立 / 判定月 / 本月收没收到完）、开窗事件（绿转红 / 矮转高 / 是否存活）、
入场参考价与突破结论。

**为什么要有它**：以前是 AI 看着 CSV 自己算，换模型就可能换结论。现在**脚本算、AI 只转述**。

**AI 使用纪律**（写进 SKILL.md）：
- 只能转述 `judgment.json` 里的 `required_statement.final_text`
- 不得自己拿 CSV 里的 DIF/DEA/MACD柱 重算（CSV 是 `round(2)`，判定用的是未取整原始值，会算出不同答案）
- `status != "judged"` 时只能原样说明原因，不得"按一般理解"补结论

**判定口径**（与 HOLDLE 回测引擎同源，已做 24 组锚点一致性校验）：
- 固定前复权；后复权（历史复盘）不做判定
- 贴0轴 `|柱|/|DEA| < 0.03`、不追 5%、MACD 12/26/9
- 本月未收完 / 次新股（<30 个月）/ 金融类 / 双线贴轴 → **明确报「不可判」，不猜**

**注意**：`judge.py` 是随主脚本一起分发的附属模块（自更新会自动下载）。
若你的目录里没有 `judge.py`，脚本仍能正常拉数据，只是不出判定结果——跑一次 `--auto-update` 即可补齐。
